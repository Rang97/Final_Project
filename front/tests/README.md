# 인증 연결 검증

백엔드를 8080 포트에서 실행하고 `front`에서 `npm run dev`를 실행합니다.
Vite는 `/api` 요청을 `http://localhost:8080`으로 전달합니다.
배포 시에도 웹 서버에서 `/api`를 백엔드로 전달하도록 설정해야 합니다.

로그인 토큰은 sessionStorage에 보관하며 새로고침 시 `/api/auth/me`로 확인합니다.
탭을 닫으면 세션이 종료됩니다. 로그아웃은 브라우저 토큰을 삭제하며 서버 토큰 폐기 API는 없습니다.
회원가입 시 사주 정보는 선택 사항입니다. 입력 시 생년월일·성별과 양력/음력·출생 시간대를 함께 전송하며, 완료 후 로그인 화면으로 전환합니다.
마이페이지 접근은 인증으로 보호되지만 기존 프로필·파티·게시글 예시 데이터는 별도 API 연결 대상입니다.

## 브라우저 회귀 테스트

Playwright와 Microsoft Edge가 있는 환경에서 개발 서버를 실행한 뒤:

```powershell
node tests/auth-flow.cjs
```

Playwright가 프로젝트 외부에 설치되어 있다면 `PLAYWRIGHT_MODULE`을 해당 모듈 경로로 설정합니다.
`TEST_BASE_URL`로 기본 주소 `http://127.0.0.1:5173`을 변경할 수 있습니다.
테스트는 API 응답을 모의 처리하며 실제 DB에 회원을 생성하지 않습니다.
아이디 형식, 비밀번호 확인, 중복 가입, 가입 성공, 로그인 실패·성공,
토큰 복원, 서버 오류 후 재시도, 모바일 로그아웃, 보호 경로와 만료 처리를 검증합니다.
